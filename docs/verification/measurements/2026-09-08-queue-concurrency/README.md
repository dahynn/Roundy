## 남은 범위

취소보다 매칭이 먼저 끝나면 큐 삭제는 false지만 HTTP leave는 성공으로 표시합니다.
이번 시험은 Redis 정원/큐 불변식 확인이며, 매칭 후 미입장자 회수와 취소 UX를
완료했다는 뜻이 아닙니다. 최초 입장보다 취소 요청이 먼저 도달하는 경계도 별도입니다.

합성 로컬 검증 및 AI 작성 구현이며 사용자 단독 기여로 자동 확정하지 않습니다.
